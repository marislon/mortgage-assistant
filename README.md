# Mortgage Assistant — система ипотечного кредитования

Учебный проект по разработке серверной части системы ипотечного кредитования на Python.

## Назначение проекта

Система предназначена для хранения информации об ипотечных кредитах и выполнения расчётов по кредитным обязательствам.

На текущем этапе реализованы:

- Расчёт ежемесячного аннуитетного платежа.
- Формирование графика платежей с разделением на основной долг и проценты.
- Досрочное погашение с сокращением срока кредита.
- Досрочное погашение с уменьшением ежемесячного платежа.
- Изменение календарного дня платежа.
- Хранение информации о кредитах в PostgreSQL.
- Проверка работоспособности приложения и подключения к базе данных.

Денежные суммы рассчитываются в целых копейках для исключения ошибок, связанных с использованием чисел с плавающей точкой.

## Технологии

- Python 3.12
- FastAPI
- PostgreSQL 16 и pgvector
- SQLAlchemy и asyncpg
- Alembic
- Temporal
- Docker Compose
- uv
- pytest

## Структура проекта

- `app/main.py` — приложение FastAPI и эндпоинты проверки состояния.
- `app/core/` — настройки и подключение к базе данных.
- `app/models/` — модели базы данных.
- `app/services/mortgage_calculator.py` — ипотечный калькулятор.
- `migrations/` — миграции Alembic.
- `tests/` — автоматические тесты.
- `docs/adr/` — документы с архитектурными решениями.
- `docker-compose.yml` — конфигурация PostgreSQL и Temporal.
- `seed_loans.py` — добавление пяти тестовых кредитов.

## Запуск проекта

Для запуска необходимы Python, uv и Docker Desktop.

**1. Установить зависимости**

```bash
uv sync
```

**2. Создать файл `.env`**

Скопировать `.env.example` в `.env` и указать параметры подключения к базе данных.

Для локального запуска с предоставленным Docker Compose:

```env
DATABASE_URL=postgresql+asyncpg://app:app@127.0.0.1:5434/app
```

**3. Запустить инфраструктуру**

```bash
docker compose up -d
```

**4. Применить миграции базы данных**

```bash
uv run alembic upgrade head
```

**5. Добавить тестовые кредиты**

```bash
uv run python seed_loans.py
```

**6. Запустить FastAPI**

```bash
uv run uvicorn app.main:app --reload
```

## Проверка работы

После запуска доступны:

- `http://127.0.0.1:8000/live` — проверка работы приложения.
- `http://127.0.0.1:8000/ready` — проверка подключения к базе данных.
- `http://127.0.0.1:8000/docs` — документация FastAPI.
- `http://localhost:8233` — веб-интерфейс Temporal.

Для запуска автоматических тестов:

```bash
uv run pytest
```
